# School mark sources

These marks are used only to identify the schools in the education timeline.
All rights remain with the respective schools.

- Shanghai Jiao Tong University: emblem crop from a public brand-reference sheet.
- Yangzhou University: public emblem reference image.
- Jiangsu Jiangyan No. 2 High School: public Baidu Baike image record for the school.
- Taizhou Jiangyan Licai Experimental School: public Baidu Baike image record for the school.
- Taizhou Jiangyan Experimental Primary School (North Street Campus): no authoritative
  high-resolution school emblem was publicly available, so a scalable typographic
  “北街” substitute is used. Replace `primary-north-street.svg` when the official
  mark is available.
